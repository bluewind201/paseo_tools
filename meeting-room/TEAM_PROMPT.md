# 📋 전사 AI 개발 가이드 (Paseo & Workspaces — 개별 AI 단독 진행 체계)

## 핵심 운영 원칙 (2026-11-13 개정)

1. **개발자·디자이너·리뷰어 역할 분리 전면 폐지 (Single-Agent End-to-End)**
   - 기존에 개발, 디자인, 리뷰로 역할을 쪼개어 여러 에이전트를 생성하던 방식은 **효율 저하 및 과도한 토큰 소모로 인해 전면 폐지**합니다.
   - 이제부터는 **개별 AI가 단독으로 기획·UI/UX 디자인·프론트엔드·백엔드·테스트·빌드 검증까지 전 과정을 처음부터 끝까지 진행**합니다.
2. **Obsidian `AI 메모리` 참고 개발 및 동기화**
   - 모든 개발 작업은 Obsidian 볼트의 **`C:\obsidian\sync_folder\AI 메모리`** (`00_AI_메모리_시스템_가이드.md`, `03_제품_메모리_인덱스.md`)와 **`C:\obsidian\sync_folder\GIT 프로젝트`** 내 해당 제품 문서를 참고하여 진행합니다.
   - 제품 수정이나 기능 업데이트가 완료되면 변경된 기능 매뉴얼, 사용법, 디렉터리 구조, 아키텍처를 해당 Obsidian 문서와 `06_업데이트_및_변경_이력_로그.md`에 즉시 반영합니다.
3. **Main AI → 각 Workspace 지시 및 결과 보고 체계**
   - **Main AI (`C:\ai`)**가 각 **Workspace (`C:\ai\<프로젝트>`)**에 작업을 지시하면, 해당 Workspace에서 개별 AI가 단독으로 작업을 완수합니다.
   - 작업 완료 후에는 불필요한 대화나 과정 설명 없이 **최종 결과(상태, 변경 파일, 검증 결과, 문서 반영 여부, 잔여 이슈)만 Main AI에게 간결하게 보고**합니다.
4. **사용량(Quota) 초과 시 대체**
   - 쓸 수 있는 AI는 `claude`, `codex`, `antigravity`(Gemini) 3가지이며, 특정 AI의 사용량이 소진되면 사용량이 남은 다른 AI가 해당 Workspace에서 단독으로 이어받아 진행합니다.

## Main AI → Workspace 지시 프롬프트 템플릿

```text
목표: <여기에 이번 작업 목표를 적어주세요>

[진행 지침]
1. 개발자·디자이너·리뷰어로 역할을 나누지 말고, 해당 Workspace(C:\ai\<워크스페이스명>)에서 네가 단독으로 디자인·코드 구현·테스트·빌드 검증까지 끝까지 진행해.
2. 작업 전 C:\obsidian\sync_folder\AI 메모리\03_제품_메모리_인덱스.md 와 C:\obsidian\sync_folder\GIT 프로젝트\<제품문서>.md 를 읽어 아키텍처와 구조를 파악하고 시작해.
3. 작업과 테스트/빌드 검증이 끝나면 변경된 기능·사용법·구조·아키텍처를 Obsidian 문서와 06_업데이트_및_변경_이력_로그.md 에 반영해.
4. 완료되면 과정 설명 없이 아래 형식으로 결과만 Main AI에게 알려줘:
   - 상태: SUCCESS | FAILED
   - 변경 파일: 주요 파일 경로
   - 검증 결과: 테스트/빌드 통과 요약
   - Obsidian 메모리 반영: 갱신한 문서명
   - 잔여 이슈: 없음 (또는 1줄 요약)
```
